```yaml
  - "Token só na primeira mensagem, em ≤ 5 s; nunca em query string; mesma validação jose da API"
  - "Ordem: assinar Pub/Sub → bufferizar → buscar faltantes (Stream/Postgres) desde lastSequence → enviar → drenar buffer deduplicando por sequence"
  - "Canal privado por sub para eventos de contrato liquidado e saldo; um usuário nunca recebe evento de outro"
  - "Limites: 5 conexões por usuário, 10 símbolos por conexão, ping 15 s, fecha após 45 s sem pong, rate limit de mensagens"
  - "Buffer por cliente limitado; cliente lento é desconectado, não derruba o processo"
  - "Token expirado com conexão aberta → fecha com 4401"
  - "Métricas websocket_connections_active e websocket_reconnects_total"
budget: { max_steps: 3, max_tokens: 400000, timeout: 90m }
```

Guardas específicas: snapshot antes de assinar (perde ticks no intervalo); JWT em query string logado;
não revalida token expirado; buffer sem limite.
