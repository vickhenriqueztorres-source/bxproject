# Skill: Mapear o Projeto

**Trigger**: mapear projeto, descobrir stack, projeto desconhecido

Use na etapa 01 e sempre que o mapa estiver desatualizado.

## Instrução

Leia integralmente `skills/16-mapear-projeto/SKILL.md` a partir da raiz do projeto. Esse arquivo define o roteiro de descoberta read-only (stack, scripts, estilo, i18n, rotas, sala de operação, dados em tempo real, hora do servidor, testes, flags, analytics) e como gravar `docs/mapa-do-projeto.md`.
