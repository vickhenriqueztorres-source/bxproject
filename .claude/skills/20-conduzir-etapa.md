# Skill: Conduzir uma Etapa

**Trigger**: "rode a etapa NN", mudança na sala de operação

Use quando o dono pedir para rodar uma etapa específica de `docs/prompts/` ou qualquer mudança na sala de operação.

## Instrução

Leia integralmente `skills/20-conduzir-etapa/SKILL.md` a partir da raiz do projeto. Esse arquivo define a ordem de chamada dos agentes, a montagem do plano, a aprovação, a execução passo a passo com o cirurgião e o guardião, e o formato do relatório final.
